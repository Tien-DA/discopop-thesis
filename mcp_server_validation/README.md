# MCP Benchmark UI

This project implements a benchmark UI for evaluating MCP (Model Context Protocol) functions to measure token usage reduction.

## Project Structure

```
mcp_server_validation/
├── README.md
├── frontend/           # Frontend components and UI
├── backend/            # Backend services and logic
├── benchmark_cases/    # Benchmark test cases
├── utils/              # Utility functions
└── tests/              # Test files
```

## Features

1. **Frontend Layer**:
   - Web UI for configuring benchmark
   - Connection to LLM models
   - MCP server selection
   - Results visualization

2. **Backend Layer**:
   - Benchmark execution engine
   - MCP client integration
   - Results processing and analysis

3. **Benchmark Cases**:
   - Predefined test cases
   - Configurable scenarios

4. **Utilities**:
   - Logging and helper functions

5. **Testing**:
   - Unit tests and integration tests
